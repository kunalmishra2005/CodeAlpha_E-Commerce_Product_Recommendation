🛍️ SmartShop AI — E-Commerce Product Recommendation System

SmartShop AI is an AI-powered e-commerce product recommendation system built with Python and Streamlit.

The system recommends products similar to the product selected by the user. It uses Natural Language Processing (NLP), TF-IDF vectorization, and Cosine Similarity to calculate product similarity.

🚀 Features

- 🔎 Product search
- 📂 Category filtering
- 🤖 AI-based product recommendations
- 🧠 TF-IDF-based text processing
- 📊 Cosine Similarity
- 💰 Product prices
- ⭐ Product ratings
- 🖼️ Product images
- 🛍️ Product catalog
- 📱 Interactive Streamlit interface

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF
- Cosine Similarity

⚙️ How to Run

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd E-commerce

3. Install the required libraries

pip install -r requirements.txt

4. Run the application

streamlit run app.py

The application will open in your web browser.

🧠 How the Recommendation System Works

Step 1 — Product Information

The system uses product names, categories, and descriptions as input data.

Step 2 — TF-IDF

TF-IDF converts the product text into numerical vectors.

Step 3 — Cosine Similarity

Cosine Similarity compares the vectors and calculates the similarity between products.

Step 4 — Recommendations

The products with the highest similarity scores are displayed as recommendations.
